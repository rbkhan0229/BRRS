### SB2000 r4: ABORTED_BEFORE_INIT (비교 데이터에서 제외)

사용자가 보드 불량 가능성과 N2/N3 물리 위치 교환을 제안하여 다음 실행 시작을 보류했다. 원격 N2/N3/N4는 READY까지 준비되었지만 이 실행의 INIT capture는 시작하지 않았다. 원격 수집기는 END STATS 미검출로 180초 timeout 종료했고, 해당 orchestrator/capture 프로세스가 남아 있지 않음을 확인했다. 준비 단계 raw/metadata/worker 로그도 로컬 SB2000 폴더에 복사해 보존했다. 이 timeout은 유효한 무선 비교 실행의 PER 결과나 새로운 RF 장애 근거로 사용하지 않는다. 이후 INIT 1050270933에 reset/halt를 수행했고 연결 중 halted=True를 확인했다.

### 물리 위치 교환 비교 (별도 폴더에서 1회 완료)

사용자 이동 완료 확인 후 같은 SB1703/SP2002 full-configure 바이너리로 1회 실행했다. 584/N2 PER 0.0→4.9%, 888/N3 36.7→5.6%, N4 0.9→1.5%, 전체 12.533→4.000%였다. 상세 결과와 한계는 `../exp4_nlos_posswap_full_6.9m_g200_l15_pac8_sb1703_sp2002_20260903_spiopt/README.md` 및 audit JSON에 보존했다. SB A/B의 추가 반복은 계속 보류하며, 위치 교환 결과를 SB 반복 데이터에 합산하지 않는다. 아래는 해당 비교 설계와 해석 기준이다.

- 1050211584는 논리 역할 N2를 유지한 채 기존 N3의 고손실 위치로 이동.
- 1050273888은 논리 역할 N3를 유지한 채 기존 N2 위치로 이동.
- INIT/N4, 허브 전원, 보드별 USB 케이블·포트 연결을 유지하고 각 위치의 원래 안테나 방향을 재현. 변경된 연결이 있으면 별도로 기록.
- 사용자 이동 완료 확인 전 무선 실행을 시작하지 않는다. 교환 후 기록은 기존 로그와 분리한 새 실행 폴더를 사용한다.
- 비교에는 교환 전후 같은 PHY/SB/SP 바이너리를 사용한다. 새로운 설정 변경을 동시에 섞지 않는다.
- 손실이 물리 위치를 따라가면 경로/위치 영향의 근거다. 손실이 888을 따라가면 보드뿐 아니라 해당 케이블·포트 또는 보드에 고정한 N3 논리 슬롯도 후보이므로, 보드 불량 확정에는 별도 역할/연결 교차 검증이 필요하다.
