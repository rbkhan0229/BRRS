# Historical experiment reports and helper code

These files mirror selected lightweight files from the original DWM3000/logs
workspace. Their original bytes and relative paths are preserved, including
historical limitations, failures, test-only results, and absolute paths.

They are provenance, not the current firmware or experiment entry point. Some
scripts flash boards or start RF if executed. Use the current campaign tools
under Drivers/API for new experiments. Raw data and binary firmware artifacts
remain in the original local workspace, indexed under docs/reproducibility.

The source-to-archive mapping and hashes are in
docs/reproducibility/legacy_publication_files.json at the repository root.
